How the community estimate works

The app uses historical reference statistics until each subject has 101 contributions. Then it calculates a community estimate using current 2026 marks.

Use actual 2026 results only

By confirming, you send your three subject names and marks to build community statistics. Guesses or false marks can distort other students’ estimates, so only share actual results. Marks are kept in restricted storage for up to 30 days so an incorrect submission can be removed, then individual marks are deleted and only subject totals remain. No name or index number is collected. A one-way code based on your network address is kept for up to 48 hours to limit spam; your address itself is not stored.
